Jira integration provides access to your project management and issue tracking data for documentation automation. When Jira is configured as a context source, Promptless can search for related tickets to understand requirements and business context. Promptless can also create new Jira issues to track documentation tasks or link documentation work to your existing workflows.

## How It Works as Context Source

When Jira is enabled as a context source:

- **Automatic Issue Retrieval**: When a GitHub PR or other trigger mentions a Jira ticket (like "PROJ-123"), Promptless automatically retrieves that specific issue for additional context
- **Proactive JQL Searches**: Promptless can proactively search Jira using JQL queries to find related issues, epics, and project data
- **Business Context**: Jira tickets provide requirements, business logic, and feature context that enhance documentation accuracy

## Example

If a GitHub PR references a Jira ticket (like "PROJ-123"), Promptless automatically reads that Jira ticket for additional context. It also proactively searches Jira using JQL for related issues and epics.

## JQL Search Capabilities

Promptless leverages Jira's powerful JQL (Jira Query Language) search functionality to find relevant context. This allows intelligent searching across your Jira projects to find related issues, epics, and dependencies.

## Jira Issue Creation

Promptless can create Jira issues to track documentation work or integrate with your existing project management workflows. When creating issues, Promptless provides:

- **Project key**: The Jira project where the issue will be created (e.g., `DOCS`)
- **Issue type**: Standard Jira issue types such as `Task` or `Bug`
- **Summary**: A short title for the issue
- **Description**: Plain-text description (Promptless converts this to the appropriate format for your Jira instance)

Promptless can also attach labels and link new issues to existing tickets in your project.

<Note>
Issue creation requires the `write:jira-work` scope. If your organization configured a limited-access Atlassian account for Promptless, ensure that account has permission to create issues in the target project.
</Note>

## Configuration

Configure Jira context in your [project settings](https://app.gopromptless.ai/projects):

1. Enable Jira as a context source for your project
2. Select which Jira projects Promptless can search within
3. Promptless will only search projects you explicitly configure

## Data Privacy and Security

Promptless queries Jira data in real-time and does not store any of your Jira data. All searches are performed on-demand when documentation updates are needed. When agents create Jira issues, only the metadata you would expect—project, type, summary, description, labels, and links—is sent to Jira.

For information about data processing and redaction capabilities, see the Atlassian integration page.
